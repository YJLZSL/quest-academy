# 归档文档

此目录存放已完成或已过期的规划文档与 spec，保留作为历史参考。

## 归档规则

- **何时归档**：当一份规划文档对应的任务全部完成、或文档已过时被新版本取代时，移入此目录
- **归档位置**：
  - `.trae/archive/` —— 归档的 documents（顶层规划文档）
  - `.trae/archive/specs/` —— 归档的 specs（含 spec.md / tasks.md / checklist.md）
- **不要修改**：归档文档保留原内容，作为决策历史参考，不再维护
- **不要删除**：归档文档对回溯项目演进与设计决策有价值

## 当前活跃文档
