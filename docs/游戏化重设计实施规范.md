# 游戏化重设计实施规范

> 范围：灵犀学院 Android + Windows 双端 Flutter 应用。
> 核心诉求：全面转向 Duolingo 式现代游戏化 UI；彻底移除吉祥物；把 Minecraft 彩蛋升级为设置页可直接切换的完整 Pixel MC 主题。
> 对应详细计划：`.trae/documents/poco-academy-gamified-redesign-implementation-plan.md`

---

## 1. 目标与成功标准

### 1.1 目标

- 移除现有吉祥物"小犀"及其状态机，替换为非角色化的游戏化反馈（streak、XP、成就徽章、粒子庆祝）。
- 建立三档一级主题：
  - **Default**：Duolingo 式活泼风格——高饱和、大圆角、卡片堆叠、强进度可视化、弹簧微交互。
  - **Minimal**：低饱和、低动效、高信息密度的专注模式。
  - **Pixel MC**：完整像素块/体素风格——直角、厚边阴影、8-bit 配色、像素字体。
- 首页具备 XP 进度环、streak 火焰徽章、每日目标、最近成就入口。
- 学习路径改为关卡节点路径，已完成/当前/锁定状态分明。

### 1.2 成功标准

- 所有页面不再引用 `MascotWidget` / `mascotControllerProvider` / `MascotHero` / `MascotOverlay`。
- `lib/features/mascot/` 目录已删除。
- 三种主题均能在设置页一键切换，颜色、形状、动效、字体随主题完整切换。
- `flutter analyze` 零 error、零 warning。
- `flutter test` 全部通过。
- 文档同步完成。

## 2. 方案调研结论

### 2.1 Duolingo 游戏化 UI 关键模式

| 模式 | 作用 | 设计特征 |
|------|------|----------|
| **Streak** | 习惯养成、日活激励 | 顶部火焰徽章、连续天数数字、中断风险提示 |
| **XP** | 学习量化、即时反馈 | 每日目标环、完成动画、+XP 浮层 |
| **关卡路径** | 进度可视化、目标感 | 纵向/横向节点、当前节点高亮、已完成打勾、锁定节点灰显 |
| **成就徽章** | 长期激励、收集欲 | 徽章网格、解锁动画、进度条 |
| **视觉风格** | 品牌识别 | 大圆角 rounded rectangle 为基础形状、高饱和色、简洁形状语言、药丸形阴影 |

Duolingo 形状语言以 **rounded rectangle、circle、rounded triangle** 为基础，强调 rhythm 与 simplicity，阴影为底部药丸形，颜色高饱和且活泼。

### 2.2 Pixel MC / Minecraft 视觉特征

| 特征 | 实现方式 |
|------|----------|
| 方块阴影 | 无模糊硬边 offset 阴影模拟体素挤出 |
| 像素字体 | 等宽像素风格显示字体（Press Start 2P / VT323） |
| 直角/小圆角 | BorderRadius.zero 或 2-4px |
| 厚边框 | 2-4px 实线边框，配合 inset/outset 视觉 |
| 8-bit 配色 | 草地绿 `#5D8C22`、泥土棕 `#8B5A2B`、石头灰 `#707070`、天空蓝 `#87CEEB` |
| 按钮按压反馈 | 整体下移 2-4px 模拟方块按下 |

## 5. 关键决策

1. **吉祥物完全移除，不做降级保留**：不保留小尺寸吉祥物或可选显示开关。
2. **Pixel MC 主题复用现有 `ThemeFlavor.minecraft`**：UI 文案称「Pixel MC」，旧用户持久化值 `'minecraft'` 仍然有效。
3. **不引入新第三方依赖**：字体使用 `google_fonts`；动画使用 Flutter 内置 + `SpringMotion`；图表使用 `CustomPainter`。
4. **Minimal 模式合并到 ThemeFlavor**：删除 `minimalModeProvider`，避免与 `themeFlavorProvider` 冲突。
5. **Duolingo 风格聚焦「路径 + 进度 + 激励」**：保留 streak、XP、成就三要素；排行榜/好友对战作为未来扩展。
6. **暗色模式与三种主题正交**：Default + dark、Minimal + dark、Pixel MC + dark 都需要单独调校对比度，确保 WCAG AA。
7. **AI 对话情绪反馈改为抽象状态**：thinking → 脉冲指示条；error → SnackBar + 输入框红边；celebrate → 全局粒子庆祝 +「+XP」浮层。
8. **本次不改动数据库 schema**：XP、每日目标基于现有 `Settings` 键值对或 `LearningEvents` 表计算。

## 6. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 吉祥物移除遗漏引用 | `flutter analyze` 失败 | 删除目录后全局 grep `mascot`、`Mascot`；修复所有引用 |
| `minimalModeProvider` 删除导致旧用户设置丢失 | 极简模式用户升级后变回 standard | 已做一次性迁移：`minimal_mode=true` → `theme_flavor='minimal'` |
| Pixel MC 字体导致中文显示异常 | 中文可读性下降 | Pixel MC 正文字体保持 NotoSansSC，仅标题使用 PressStart2P |
| 学习路径重设计影响导航逻辑 | 用户无法进入 lesson | 保留课程 ID/课时 ID 路由参数；仅改视觉布局 |
| 成就服务移除 mascot 后缺少反馈 | 用户解锁成就无感知 | `AchievementService` 返回解锁事件，UI 层触发 `CelebrationService` + SnackBar |
| 暗色模式 WCAG 对比度不达标 | 可访问性问题 | 使用 DevTools 对比度检查；对 Pixel MC 暗色单独校准固定色 |
| 大范围改动导致测试回归 | CI 失败 | 每阶段运行 `flutter test` 子集；最终运行完整测试 |
